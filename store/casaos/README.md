# HaVeWa — CasaOS app source

A one-app CasaOS store. Add it in CasaOS under *App Store → Add source* with this URL:

```
https://github.com/fgilde/hausverwaltung/releases/download/store/casaos-appstore.zip
```

The archive is rebuilt from `store/casaos/` on every push. Source and issues: https://github.com/fgilde/hausverwaltung
